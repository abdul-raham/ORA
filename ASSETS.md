# Assets

ORA currently uses no external photography. Every visual — the smile aperture,
dental arches, shade guide, chair lanes, impression contours and CarePass
impression code — is drawn in code (SVG/CSS) inside `src/components/ora`.

| Asset | Source | Licence | Usage |
| --- | --- | --- | --- |
| Fraunces | Google Fonts (Undercase Type) | SIL Open Font License 1.1 | Display type |
| Geist, Geist Mono | Google Fonts (Vercel) | SIL Open Font License 1.1 | Body and clinical labels |
| Favicon | Original, `public/favicon.svg` | Project-owned | Browser tab |

When editorial photography is added, download and optimise it locally under
`public/images/`, and record each file here with its source URL, creator and
intended usage. Do not hotlink.
